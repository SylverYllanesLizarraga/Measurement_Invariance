# PART_O_Measurement_Invariance
Measurement Invariance analysis of the Participation Assessment with Recombined Tools-Objective (PART-O), with data from the  Traumatic Brain Injury Model System (TBIMS)

- File 1 "MI_PARTO_1_DataClean": initial data-clean from the TBIMS data.
- File 2 "MI_PARTO_2_ModelFitting": exploratory and confirmatory analysis to find a fitting model.
- File 3 "MI_PARTO_3_CrossSectionalMI" & File 4 "MI_PARTO_4_LongitudinalMI": cross-sectional and longitudinal measurement invariance analyses.
- File 5 "MI_PARTO_5_ScorePredictors": Modeling of factor scores with sociodemographic and injury variables. Requires "W_Fscores.rds", "B_Fscores.rds" and "H_Fscores.rds". Optionally, can use "W_predScores.rds", "B_predScores.rds" and "H_predScores.rds"

The first four files would require data from the TBIMS to replicate the results.
